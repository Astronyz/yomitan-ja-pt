**Pré-lançamento.** Dicionários Yomitan japonês → português brasileiro. A estrutura está completa e validada, mas a maior parte das glosas do Jitendex-PT ainda está em inglês. Cada entrada traz uma tag com o estado da tradução: `pt-automatica`, `pt-reaproveitada`, `pt-parcial` ou `pt-pendente`.

Importe os ZIPs em **Yomitan → Dictionaries → Configure → Import**. Os arquivos `.json` são os índices de atualização, que o Yomitan consulta sozinho; não é preciso baixá-los.

| Arquivo | Conteúdo |
|---|---|
| `Jitendex-PT.zip` | Termos. 11% das entradas com glosa estão inteiramente em PT, 11% parciais e o resto em inglês |
| `JMnedict-PT.zip` | Nomes próprios |
| `KANJIDIC-PT-completo.zip` | Kanji, com significados em português |
| `JMdict-PT-bonus.zip`, `wty-ja-pt.zip` | Bônus, idênticos às fontes abertas |

Números completos em [docs/RELATORIO.md](https://github.com/CosmionLabs/yomitan-ja-pt/blob/main/docs/RELATORIO.md). Dados sob CC BY-SA 4.0, código sob MIT.
